# 📱 UGC ICON — Premium Mobile Landing Page

Сучасний, високооптимізований та естетичний мобільний лендінг для курсу **Inna Dugina зі створення UGC-відео**. Проект орієнтований на максимальну конверсію, бездоганний мобільний UX та високу швидкість роботи.

---

## 🚀 Технологічний стек

* **Frontend:** Семантичний HTML5, сучасний ванільний CSS3 (з підтримкою змінних та скляного ефекту), чистий JavaScript (ES6+).
* **Анімації та Ефекти:** 
  * [AOS.js (Animate On Scroll)](https://github.com/michalsnik/aos) — для плавних інтерактивних появ елементів при скролі.
  * [VanillaTilt.js](https://micku7zu.github.io/vanilla-tilt.js/) — для преміального 3D-ефекту нахилу карток тарифів.
* **Архітектура:** Повністю автономна статична веб-сторінка без зовнішніх залежностей та без серверного збирання.

---

## ✨ Ключові особливості та UX-фічі

1. 🎨 **Преміальний дизайн та мікро-інтеракції:**
   * Елегантний логотип `UGC ICON` із контрастним накресленням шрифтів та градієнтним сяйвом.
   * Скляний бейдж `"КОНТЕНТ, ЩО ВИРІШУЄ"` із пульсуючим неоновим зеленим індикатором активного запису (Live-статус).
   * Індивідуальне градієнтне обведення для Instagram-кнопки (виконано на чистих inline SVG масках).
   * М'який плавний тактильний відклик (активний стан кнопок та карток) для максимальної імітації нативного мобільного додатку.

2. 📱 **Абсолютна оптимізація під iOS Safari:**
   * Усунено конфлікти 3D-трансформацій VanillaTilt у Safari (вирішено проблему лагів при переходах та обрізання сусідніх карток за допомогою динамічного накладання шарів `z-index`).
   * Індикатор прогресу скролу адаптований під приховані горизонтальні області обрізки (`overflow-x: hidden`).

3. ⚡ **Максимальна продуктивність (Performance):**
   * **Self-Hosting бібліотек:** Усі сторонні ресурси (AOS та VanillaTilt) завантажені локально в репозиторій. Жодних залежностей від зовнішніх CDN-серверів.
   * **Throttled Scroll:** Розрахунок скрол-бару оптимізований через `requestAnimationFrame`, що повністю усуває смикання інтерфейсу при швидкій прокрутці.
   * **Медіа-оптимізація:** Швидке передзавантаження метаданих для відео-вітрини (`preload="metadata"`) та ліниве завантаження (`loading="lazy"`) для другорядних зображень.

4. ⏳ **Розумний таймер знижки (Evergreen Timer):**
   * Таймер зворотного відліку не просто оновлюється кожну добу, а використовує `localStorage` для прив'язки персонального дедлайну до конкретного пристрою відвідувача. Це створює реальний психологічний тригер без зниження довіри до бренду при випадковому оновленні сторінки.

## 📁 Структура проекту

```bash
inna_dugina/
├── css/
│   ├── style1.css          # Основні преміальні стилі лендінгу
│   └── aos.css             # Локалізовані стилі бібліотеки анімацій AOS
├── js/
│   ├── script.js           # Головний файл скриптів сайту (таймер, скрол-бар)
│   ├── aos.js              # Локалізована бібліотека AOS.js
│   └── vanilla-tilt.min.js # Локалізована бібліотека 3D-нахилу VanillaTilt
├── img/                    # Папка з медіа-ресурсами, іконками та фото
├── video/                  # Папка з відео-контентом для демонстрацій
├── index.html              # Головна сторінка лендінгу
├── oferta.html             # Договір оферти
└── politik.html            # Політика конфіденційності
```

## 🔧 Локальний запуск та деплой

1. **Локальний запуск:**
   * Оскільки проект є повністю статичним, його можна запустити просто відкривши файл `index.html` у будь-якому сучасному браузері.
   * Для розробки рекомендується використовувати розширення типу **Live Server** у VS Code для миттєвого відображення змін.

2. **Деплой:**
   * Сайт готовий до публікації на будь-якому статичному хостингу (**GitHub Pages**, **Netlify**, **Vercel** або звичайний FTP-сервер).
   * Просто скопіюйте всі файли репозиторію в кореневу папку вашого веб-сервера.
